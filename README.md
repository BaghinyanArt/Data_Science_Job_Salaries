# 💼 Data Science Job Salaries

This project explores salary trends in the data science field using a dataset from Kaggle. The goal is to analyze how factors like job title, location, experience level, and employment type affect compensation.This project also includes many interesting manipulations with non-numeric data.

---

## 📊 Dataset

- **Source**: [Kaggle - Data Science Job Salaries](https://www.kaggle.com/datasets/ruchi798/data-science-job-salaries)
- **Author**: [Ruchi Bhatia](https://www.kaggle.com/ruchi798)
- **Description**: This dataset includes job salary data for various roles in the data science domain, collected from 2020 to 2023.  
- **Size**: ~375 records with columns like:
  - `job_title`
  - `salary_in_usd`
  - `experience_level`
  - `employment_type`
  - `company_location`
  - `remote_ratio`
  - `company_size`
  - and more.

## 📌 Project Objectives

- Analyze salary trends in data science roles from 2020–2023
- Explore how experience level, company size, and job location impact salary
- Visualize global distribution of data science salaries
- Work with non-numeric data for deeper categorical insights
- Bonus: Compare salary data with GDP of different countries
